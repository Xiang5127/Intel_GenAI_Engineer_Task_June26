Agents are local backend code modules. 
They are called by the executor. 
Each agent owns a category of tasks and calls relevant MCP servers.

Planner decides the steps.
Executor calls agents.
Agents know how to perform their task.
Agents call MCP tools.
MCP tools run actual local capabilities.

First, we have a MCP Client Manager
- do all connections
- Start/connect to local MCP server processes.
- Maintain MCP client sessions.
- List available tools.
- Provide agents with access to specific MCP clients.
- Handle tool call errors/timeouts.
- Keep MCP connection setup out of agent code.
