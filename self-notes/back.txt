1. gRPC server
2. Router / Validator / Executor
3. Agents
4. MCP-style tool servers
5. Services/model runtimes/storage

Components: 
- gRPC server
- Router LLM
- Plan Validator
- Elicitation/Clarification Manager
- Plan Executor
- Agent registry
- MCP client manager
- SQLite storage

FLOW: 
1. gRPC server receives ChatRequest.
2. Save user message to SQLite.
3. ContextBuilder builds compact context.
4. Planner LLM creates JSON execution plan.
5. PlanValidator validates the plan with code.
6. If invalid:
     a. try one repair, or
     b. ask clarification.
7. If valid:
     PlanExecutor executes steps.
8. Executor calls agents.
9. Agents call MCP servers through MCP clients.
10. MCP servers call tools/models/libraries.
11. Results are saved.
12. Assistant response is saved.
13. gRPC returns ChatResponse to frontend.
