## OpenVINO Integration
The vision pipeline uses OpenVINO Runtime for local object-detection inference on sampled video frames. 
The MCP vision server exposes tools such as `detect_objects` and `count_objects`; 
internally these tools call an OpenVINO runtime wrapper that loads the optimized model, 
preprocesses frames, runs inference on CPU, and returns structured JSON results to the agent layer.
The runtime layer is abstracted so transcription and planner LLM models 
can later be migrated to OpenVINO GenAI or Optimum Intel without changing the frontend, 
gRPC API, planner, executor, or MCP tool contracts.

Description: 
This MVP is a local AI desktop application built with React + Tauri and a Python gRPC backend. 
The backend maintains session memory with SQLite, builds context for a local planner LLM, validates the planner’s JSON execution plan, and executes it through deterministic agents. 
Each agent calls self-developed local MCP servers for video processing, transcription, vision analysis, and report generation. 
AI inference runs locally using Hugging Face or OpenVINO-backed runtimes, with OpenVINO initially used in the vision pipeline. 
Generated PDF/PPT outputs and chat history are stored locally.
